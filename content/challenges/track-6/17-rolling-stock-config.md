# Rolling Stock Software Configuration Management

## Problem Statement

Software configurations of rolling stock are managed using heterogeneous and outdated approaches. This creates risks regarding safety, cybersecurity, traceability, and long‑term maintainability.

## Proposed Solution

Design a common configuration‑management concept for rolling stock software across operators. The focus lies on versioning, traceability, and alignment with safety‑critical railway requirements.

## Required Expert Profiles

* Systems and rolling‑stock engineers
* Software configuration management experts
* Cybersecurity specialists
* Safety and compliance professionals
